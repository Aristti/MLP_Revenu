#  Income Prediction Using a Neural Network

##  Overview

This project applies a **Multi-Layer Perceptron implemented from scratch** to predict income categories from demographic and professional information.

The objective is to build a complete machine learning pipeline, from data preprocessing to model evaluation.


##  Objectives

* Prepare and analyze the dataset
* Transform categorical and numerical features
* Train a neural network classifier
* Evaluate prediction performance
* Understand the application of neural networks to real-world problems

## Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Flask
